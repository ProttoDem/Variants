# Варіанти — Halloween Edition

Невелика браузерна гра для онлайн-тімбілдингу. Є кімнати з кодом, панель ведучої, написання брехні, голосування, розкриття та підрахунок балів.

## Вимоги
- Node.js 20 або новіший
- Інтернет для завантаження залежностей під час першого запуску

## Запуск на своєму комп'ютері
1. Розпакуй ZIP.
2. Встанови Node.js з https://nodejs.org/ (якщо ще не встановлений).
3. Відкрий папку проєкту в терміналі / PowerShell.
4. Виконай:
   ```bash
   npm install
   npm start
   ```
5. Відкрий http://localhost:3000

## Як протестувати
- В одній вкладці створи кімнату як ведуча.
- В іншій вкладці відкрий той самий сайт, введи код кімнати та ім'я гравця.
- Щоб тестувати з телефону або з комп'ютерів колег, сайт має бути опублікований в інтернеті.

## Як опублікувати для команди
Найпростіший шлях — розмістити проєкт як Node web service на Render:
1. Створи репозиторій на GitHub і завантаж файли проєкту.
2. На https://render.com створи **New → Web Service** та підключи репозиторій.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Після розгортання відкрий URL, який видасть Render, і надішли його команді.

План безкоштовного хостингу та його обмеження можуть змінюватися. Для одноразового заходу створи кімнату незадовго до гри.

## Важливо
- Це MVP: кімнати зберігаються в оперативній пам'яті сервера. Якщо сервер перезапуститься, активна гра зникне.
- Не створюй кімнату задовго до події.
- Кожен раунд налаштовує ведуча: запитання, правильна відповідь і пастка.
- Усі відповіді вводяться вручну. У цьому варіанті немає акаунтів, бази даних чи збереження історії ігор.
- Перш ніж проводити реальну гру, перевір усі сценарії у двох-трьох вкладках.
